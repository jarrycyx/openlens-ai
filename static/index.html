Quick Start

Get up and running with OpenLens AI in just a few simple steps

What You'll Need

  • Python 3.9 or higher
  • Docker (for OpenHands runtime environment)
  • API keys for LLM service (e.g., DeepSeek, OpenAI, Qwen, etc.)
  • Tavily search API key (for literature search)

Make sure you have all the necessary requirements before proceeding with installation.

Installation Steps

# Step 1: Clone the repository
git clone git@github.com:jarrycyx/openlens-ai.git
cd agent-med

# Step 2: Install dependencies
conda create -n py312 python=3.12
conda activate py312
pip install --upgrade pip
pip install -e .

# Step 3: Configure environment variables
cp .env.example .env
# Edit .env with your API keys and model settings

After installation, make sure to configure your environment variables with the necessary API keys.

Running OpenLens AI

Option 1: Command Line Interface

python -m openlens_ai.build_graph --question "Your research question" --dataset-path "path/to/dataset" --thread-id "Unique id for this job"

Option 2: Interactive Web Interface

streamlit run start_app.py

Then open your browser to http://localhost:8501 to access the interactive interface.
